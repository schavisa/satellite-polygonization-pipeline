# satellite-polygonization-pipeline
An end-to-end geospatial pipeline that transforms raw satellite imagery into structured vector polygons (GeoJSON), using raster preprocessing, optional deep learning segmentation, and raster-to-vector conversion.

# 🚀 Features
📥 Download satellite imagery (Sentinel-2 / Landsat)
🌐 Reproject GeoTIFF to target CRS
✂️ Clip raster by bounding box
🧩 Polygonize raster masks into vector data
🐳 Fully containerized with Docker
